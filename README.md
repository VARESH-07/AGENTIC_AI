# Ripple AI - Phase 1

Ripple AI is an Agentic Code Impact Investigator and AI Detective.
This repository contains Phase 1: The Backend Intelligence Foundation.

## Features (Phase 1)
- Language-agnostic code parsing (via Tree-sitter).
- Symbol extraction (classes, methods, functions) across Python.
- Relationship mapping (CONTAINS, CALLS).
- Dependency Graph generation (via NetworkX) and Impact Analysis.
- Git repository analysis and diff visualization.
- File-system based fast code search.
- Safe Test Discovery and Execution sandbox.
- Rich FastAPI Backend APIs for querying code intelligence.
- Extensible Agent Tools Interface (`agent_tools.py`) for future ReAct Agent integration.

## Project Structure
```
ripple-ai/
├── backend/
│   ├── app/
│   │   ├── analysis/     # AST parsing, symbol extraction, relationships, graph
│   │   ├── api/          # FastAPI routes
│   │   ├── database/     # SQLite configuration

│   │   └── main.py       # FastAPI application entrypoint
│   └── setup_sample_repo.py # Helper script to bootstrap a test repo
├── sample-repositories/  # Test repositories generated by setup scripts
├── tests/                # Verification and integration tests
├── requirements.txt      # Python dependencies
└── README.md
```

## Getting Started

1. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Run the demo verification:**
   ```bash
   python backend/setup_sample_repo.py
   python tests/demo_verification.py
   ```

3. **Start the FastAPI Backend:**
   ```bash
   python backend/app/main.py
   ```
   Navigate to `http://localhost:8000/docs` to view the API documentation.
